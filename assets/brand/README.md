# Farefully Foodie F

Approved Canva master: https://www.canva.com/design/DAHcNq0qWVs/edit

Forest #073B29, yellow #FFD230, white #FFFFFF. Strapline: Big appetites. Smarter budgets.

The fork, F and accents are reconstructed from the native Canva vector paths, not an AI bitmap. The web wordmark uses outlined Inter Display ExtraBold Italic as a portable approximation of the Canva lettering. The primary lockup assumes a white surface; the reversed lockup assumes forest green. The standalone icon works on other surfaces.
